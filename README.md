# PAO202651_ARQSOFT_NRC36883

Arquitectura de Software (ESPE) – Grupo 07.
Integrantes: Miranda Alison, Morán Lenin, Vivanco Gabriel.

Sistema **Conversión de Unidades Monster**: convierte unidades de longitud, masa y temperatura desde cuatro clientes (consola, escritorio, web y móvil) que consumen un mismo servidor. Sin base de datos.
Credenciales de práctica: usuario `monster`, clave `monster9`.
