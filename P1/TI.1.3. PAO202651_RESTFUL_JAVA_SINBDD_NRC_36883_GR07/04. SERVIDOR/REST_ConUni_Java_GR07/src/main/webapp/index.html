Conversión de Unidades Monster

API REST (Jakarta REST, JSON sobre HTTP) del Grupo 07. Primero se llama a POST /api/auth/login para obtener un token; ese token se envía en el encabezado Authorization: Bearer en el catálogo y en cada conversión.

RecursoMétodo y URIEntrada
LoginResourcePOST /api/auth/loginJSON: usuario, clave
CatalogoResourceGET /api/catalogo/categorias
GET /api/catalogo/{categoria}/unidades		Authorization: Bearer token
ConversionResourcePOST /api/conversiones/{categoria}JSON: valor, unidadOrigen, unidadDestino; Authorization: Bearer token

Todos los recursos devuelven estado, codigo y mensaje, con resultado, unidadOrigen y unidadDestino en las conversiones, token en el login y datos en el catálogo. El código de estado HTTP indica el resultado (200, 400, 401, 422 o 500).
