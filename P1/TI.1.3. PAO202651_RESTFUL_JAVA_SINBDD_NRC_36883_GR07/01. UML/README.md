# UML - TI.1.3

Los modelos UML XMI 2.1 para importar en PowerDesigner están en `04. XMI PARA IMPORTAR`. Incluyen casos de uso, actividad de conversión, secuencia REST, clases y arquitectura.

Los archivos XMI son modelos de intercambio; no son archivos nativos `.oom` ni exportaciones `.png`. PowerDesigner 16.5 está instalado, pero su automatización no inicia con la licencia vencida (COM `80080005`). Para completar el formato de entrega, importa cada XMI cuando la licencia esté activa, organiza la vista del diagrama, guarda el modelo como `.oom` y exporta cada diagrama a `.png`.

Los archivos `.puml` preexistentes se conservan como referencia temporal; no son el formato final solicitado. TI.1.3 no requiere MER porque no utiliza base de datos.
