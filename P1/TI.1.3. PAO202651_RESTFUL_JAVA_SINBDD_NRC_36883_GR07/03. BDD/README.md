# Base de datos - TI.1.3

Esta entrega no utiliza base de datos. No se requiere instalar un SGBD, configurar credenciales de conexión, crear tablas ni ejecutar migraciones. Usuarios, catálogo y sesiones se mantienen en memoria y se pierden al detener el proceso.

El diseño de negocio de `02. MER` documenta entidades conceptuales transitorias; no corresponde a un esquema físico.
