# Documentación - TI.1.3

- `01. DICCIONARIO DE DATOS/DiccionarioDeDatos_GR07.docx`: contrato JSON, datos en memoria, rutas y códigos HTTP.
- `02. MANUAL TECNICO/ManualTecnico_GR07.docx`: herramientas, arquitectura, API REST, despliegue Payara, pruebas, red, solución de problemas, los cinco diagramas UML y código fuente de las clases Java.
- `03. MANUAL DE USUARIO/ManualDeUsuario_GR07.docx`: uso de consola, escritorio, web y móvil.
- `PRESENTACION/PRESENTACION TI.1.3 RESTful Java sin BDD GR07.pptx`: presentación de 81 diapositivas.

ERS y ECUD están en `01. UML`; la ECUD incluye el diagrama de casos de uso. Los cinco diagramas finales tienen archivos nativos `.oom` y exportaciones `.png` en `01. UML/03. DIAGRAMAS`. Los XMI de `01. UML/04. XMI PARA IMPORTAR` se conservan solo como intercambio auxiliar.

Los documentos Word incluyen portada e índices de contenido, ilustraciones y tablas. En Word, actualiza los campos con `Ctrl+A` y `F9` para refrescar los índices.

La documentación detallada del API y la ejecución del servidor también está en `04. SERVIDOR/REST_ConUni_Java_GR07/README.md`.
