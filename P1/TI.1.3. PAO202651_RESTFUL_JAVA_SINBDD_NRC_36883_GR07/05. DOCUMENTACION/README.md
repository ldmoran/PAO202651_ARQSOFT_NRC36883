# Documentación - TI.1.3

- `01. DICCIONARIO DE DATOS/DiccionarioDeDatos_GR07.docx`: contrato JSON, datos en memoria, rutas y códigos HTTP.
- `02. MANUAL TECNICO/ManualTecnico_GR07.docx`: herramientas, arquitectura, API REST, despliegue Payara, red, solución de problemas y código fuente de las 55 clases Java.
- `03. MANUAL DE USUARIO/ManualDeUsuario_GR07.docx`: uso de consola, escritorio, web y móvil.
- `PRESENTACION/PRESENTACION TI.1.3 RESTful Java sin BDD GR07.pptx`: presentación de 81 diapositivas.

Los documentos Word incluyen portada azul e índices de contenido, ilustraciones y tablas. En Word, actualiza los campos con `Ctrl+A` y `F9` para refrescar los índices.

ERS y ECUD están en `01. UML`; cinco modelos UML XMI 2.1 para importar en PowerDesigner están en `01. UML/04. XMI PARA IMPORTAR`. Son archivos de intercambio, no modelos nativos `.oom` ni exportaciones `.png`. La automatización local de PowerDesigner 16.5 no inicia con la licencia vencida (COM `80080005`); la conversión a `.oom` y las exportaciones deben completarse al recuperar una licencia activa.

La documentación detallada del API y la ejecución del servidor también está en `04. SERVIDOR/REST_ConUni_Java_GR07/README.md`.
