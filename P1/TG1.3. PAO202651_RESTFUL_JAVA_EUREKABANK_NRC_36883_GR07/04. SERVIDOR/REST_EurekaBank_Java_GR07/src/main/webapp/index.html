EurekaBank

API REST (Jakarta REST, JSON sobre HTTP) con base de datos MySQL del Grupo 07. Primero se llama a POST /api/sesion/login; después se consultan las cuentas y se registran los movimientos.

RecursoMétodo y URIEntrada
SesionResourcePOST /api/sesion/loginJSON: usuario, contrasena
CuentaResourceGET /api/cuentasSin cuerpo
MovimientoResourceGET /api/movimientos?cuenta=00100001
GET /api/movimientos/tipos
POST /api/movimientos		 POST: JSON con cuentaOrigen, cuentaDestino, tipo e importe

Tipos de movimiento: DEPOSITO, RETIRO y TRANSFERENCIA. El código de estado HTTP indica el resultado (200, 400, 401, 422 o 500).
