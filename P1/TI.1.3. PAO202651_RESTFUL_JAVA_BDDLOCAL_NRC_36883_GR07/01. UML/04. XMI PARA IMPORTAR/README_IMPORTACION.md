# Modelos XMI auxiliares

Esta carpeta conserva modelos de intercambio XMI 2.1 creados durante la preparación de TI.1.3. No son los archivos finales de entrega ni necesitan importarse para abrir los diagramas.

Los modelos nativos de PowerDesigner y sus exportaciones `.png` están en `../03. DIAGRAMAS`. Para editar un diagrama, abre directamente el archivo `.oom` correspondiente con PowerDesigner 16.5.

| Archivo XMI | Contenido |
|---|---|
| `CasosUso_TI13.xmi` | Casos de uso |
| `ActividadConversion_TI13.xmi` | Actividad de conversión |
| `SecuenciaConversion_TI13.xmi` | Secuencia REST |
| `Clases_TI13.xmi` | Clases principales |
| `Arquitectura_TI13.xmi` | Componentes y capas |
