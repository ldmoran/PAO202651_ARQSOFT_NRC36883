Conversión de Unidades Monster

Servicios web SOAP (Jakarta JAX-WS) del Grupo 07. Primero se llama a login para obtener un token; ese token se envía en el catálogo y en cada conversión.

ServicioOperaciónWSDL
WSLoginlogin(usuario, clave)WSLogin?wsdl
WSCatalogoobtenerCategorias(token)
obtenerUnidades(token, categoria)		WSCatalogo?wsdl
WSLongitudconvertirLongitud(valor, unidadOrigen, unidadDestino, token)WSLongitud?wsdl
WSMasaconvertirMasa(valor, unidadOrigen, unidadDestino, token)WSMasa?wsdl
WSTemperaturaconvertirTemperatura(valor, unidadOrigen, unidadDestino, token)WSTemperatura?wsdl

Todas las operaciones devuelven estado, codigo, mensaje, resultado, unidadOrigen y unidadDestino (más token en el login y datos en el catálogo).
