# ClienteConsola - EurekaBank (.NET)

Menu numerado: iniciar sesion, ver cuentas, ver movimientos, deposito, retiro, transferencia y cerrar sesion.
No contiene reglas del banco: todo se valida en el servidor (SQL Server).

    dotnet run                      # usa EUREKA_URL o http://localhost:5081
    dotnet run -- http://IP:5081

Usuario de demostracion: lmoran / Eureka2026!
